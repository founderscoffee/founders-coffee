# Governance

founders.coffee is a founder-led project. Its code is open source, and the same code runs the live
service, so the people who run that service decide where the project goes. This document says who
they are, how decisions are made, and how that can change.

## Roles

- **Maintainers** set the project's direction and scope, review and merge pull requests, cut
  releases, handle security reports, and act as moderators under the
  [Code of Conduct](./CODE_OF_CONDUCT.md). They are listed below and in
  [`.github/CODEOWNERS`](./.github/CODEOWNERS).
- **Contributors** are everyone who files an issue, answers a question, reviews, translates, or
  writes documentation or code.
- **Triagers** are trusted contributors who may label, assign and close issues. The role exists for
  when the project needs it, and has no members yet.

## How decisions are made

- **What ships, and when,** is decided in the [implementation plan](./docs/implementation-plan.md),
  the project's only live specification. Propose a change to it in an issue, or in
  [Ideas](https://github.com/founderscoffee/founders-coffee/discussions/categories/ideas).
- **How code is written** is decided in [AGENTS.md](./AGENTS.md). A change to it is a pull request
  that explains why, and it needs a maintainer's approval.
- **Everything else** is settled in the issue or pull request where it comes up. Maintainers aim for
  agreement. When there is none, a maintainer decides and writes down why.

## Becoming a maintainer

Several months of steady, high-quality contributions and reviews, and good judgement in discussion,
can lead to an invitation to triage and later to maintain. The existing maintainers decide on new
ones and add them to this file and to CODEOWNERS. A maintainer who steps back is thanked here and
removed from both.

## Changing this document

Changes are made by pull request, with a maintainer's approval.
