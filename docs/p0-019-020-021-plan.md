## Risks / edge cases
- **API token scopes** — must have D1/R2/KV/Queues/Vectorize/Email edit perms; widen if denied.
- **Email/Access are DNS/dashboard-gated** — user adds founders.coffee DNS + the Zero Trust app. Apps deploy as shells without them.
- **Free-tier limits** — Workers free 10ms CPU (SSR), Workers AI/Vectorize metered beyond small volume. Flip to Workers Paid ($5) for production SSR headroom.
- **CI deploy of bare apps** — admin/ui/dashboard have no bindings yet; they deploy as empty Workers (expected).
- **GitLab shared runners** — free CI minutes quota; nx + npm cache minimize repeat work.
